Improved 4-Class Lung Cancer — Training Report
=======================================================

ROOT CAUSES FIXED:
  1. Merged train+valid (685) → 80/20 stratified re-split
     → Validation set: 72 → 137 (more reliable early stopping)
  2. Class-weighted loss (balanced) → penalises hard classes more
  3. Label smoothing 0.1 → better generalisation
  4. Removed HorizontalFlip (invalid for CT anatomical axis)
     Added: RandomAffine, GaussianBlur, RandomErasing
  5. Unfreeze last 4 backbone blocks (was 2) → more task-specific
  6. Head: +BatchNorm layer between Linear layers
  7. CosineAnnealingLR (was ReduceLROnPlateau)
  8. Gradient clipping (1.0)
  9. Optimise on macro-F1, not loss
